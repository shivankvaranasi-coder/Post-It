PostIt is a simple web application for creating, viewing, editing, and deleting posts. Inspired by micro-blogging platforms, it allows users to quickly share thoughts and view posts in real-time.

Features

Create new posts with a username and content.

View all posts in one place.

Edit existing posts.

Delete posts.

Unique ID generation for each post.

User-friendly interface with EJS templating.

Supports method override to handle PATCH and DELETE requests in forms.

Tech Stack

Backend: Node.js, Express.js

Templating Engine: EJS

Unique ID generation: UUID

Middleware: method-override, express.urlencoded

Static files: Served via Express from the /public folder
